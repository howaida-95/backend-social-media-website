## Story 1.3 — Upload post images

Tasks

 Configure Multer

 Generate unique filename
 Save uploaded file
 Save URL in database
 Handle upload failure
 Clean up uploaded files when DB operation fails
 Return image URLs
Important

Don't save image binary data in MySQL.

Use:

MySQL
   ↓
image URL

File storage
   ↓
actual image

For development:

/uploads

Later:

S3 / Cloudinary / R2
